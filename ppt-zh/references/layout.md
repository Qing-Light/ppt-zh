# 论文组会 PPT 版式与图片规范

坐标和尺寸单位为英寸，字体单位为 pt；像素指标用于 PDF 或 DOCX 渲染页中的 300 DPI 图片。
技术路线统一为默认 5 个阶段，按实际研究流程可用 4–6 个。

## 参数配置与应用

排版必须读取 [layout-tokens.json](layout-tokens.json)，使用其中数值初始化生成工具的样式和尺寸。配置为数值默认值的维护入口；本文件解释布局意图。同步更新主技能中的摘要参数，避免出现两套默认值。

- `slide`、`colors`、`title`、`header_line`、`body` 控制公共样式；`cover`、`outline`、`methods`、`result`、`subheading` 控制各类页面；`images`、`panels`、`preview` 控制图片处理与预览。
- 坐标为默认锚点，不是强行固定的文字框高度。`range` 表示允许区间，`preferred_range` 是推荐值；调整布局时遵守 workflow 的冲突优先级。
- 仅标题字体明确指定微软雅黑；其他字体沿用任务选定的中文字体并记录。缺少字体时选用可用中文字体、记录替代并重新渲染，不能声称字体完全一致。
- `gray` 表示原规则只规定灰色、没有精确色值；生成时选择明确的 RGB 并记入工作清单，不把它当十六进制值传给工具。后续若用户确定色值，再更新配置。
- 使用者在 manifest 中记录 `layout_config_version`、实际字体和 `layout_overrides`（字段路径、默认值、采用值、原因）。用户已有明确要求时直接执行并记录，无需重复确认。
- 多 panel 像素间距按300 DPI的排版画布计算；宽高比误差比较原 panel 与最终显示比例。原图提取不必为了凑 DPI 重新采样；有效清晰度取决于像素数及最终显示尺寸。
- 小节标题内容是该图/该节主题，置于页眉线与主图之间。结论居中且整句蓝色；背景和不足正文统一黑色。默认不自动选择关键词标红，仅按用户明确指定的内容添加红色强调；封面红色标题与论文原图颜色保留。
- 标红时仅拆分同一文本框内的文字 run 并改变颜色，拼接后的文字必须与未分色终稿一致；禁止在红色 run 首尾补空格、制表符或全角空格。中文及标点紧邻显示，保留原有英文词间或数字与单位间的必要空格，并逐页查看分色边界。

此配置提供统一参数输入，并非独立 PPTX 生成器。当前结构验收脚本不读取全部样式参数，也不证明所有字体、颜色和间距均已符合配置；仍须生成工具应用并逐页核验。

## 技术路线、图页与封面做法
技术路线
•  位置与结构：P4，研究背景之后、结果讨论页之前；两列表格（研究阶段 / 主要内容），表头 + 4–6 个阶段（参考 5 个），不要序号列；总页数变为 N+5。
•  字体与对齐：表格 22pt，表头、阶段、内容全部居中；表头浅蓝 #5B9BD5 白字，隔行 #D9D9D9 / 白，细灰边框；阶段名加粗；化学式用原生上下角标（C₆Cl、ZnCl₂、Cl⁻、Cl₃⁻），不要写成普通字符。
•  目标句：表格下方 24pt、#0070C0、单句单行居中（y≈6.55）；内容按论文实际流程写（参考：电解液设计 → 机制设计 → 结构表征 → 性能与机制 → 普适性验证），不新增数据/图。
图页
•  一张主图一页，按 Fig.1–N；不拆图，保证 N+5。
•  PDF 以 300 DPI 裁切；DOCX 优先提取原始内嵌图片，无法直接提取时再以 300 DPI 渲染页裁切。保留 panel 字母、坐标轴、图例、比例尺、显著性；不拉伸，宽高比误差 <0.5%。
•  结果页底部图注优先文字版：9–10pt 加粗；与结论间距 0.05–0.06 in。
•  图内默认不新增红色强调；仅用户明确指定时添加，红色 ≤8 处，不遮数据；图内不重绘、不加新数据。
•  多子图排版：合成图宽高比控制在 2.0–3.2（推荐 2.2–2.6）；行式布局，每行 panel 按行高等比缩放、顶部对齐，行内与行间间距一致（20–30px）；禁止「一行只有 1 个 panel」和行尾大面积留白；超高 panel 可作为跨两行的右侧列（与相邻两行等高对齐），不得单独占一行。
•  行宽与空白：各行右边界差 ≤2%（行宽对齐）；合成图内连续空白区域 ≤画布面积 10%；四周白边 ≤30px；单 panel 放大 ≤1.15×（避免插值模糊）；不得裁掉 panel 字母、坐标轴、图例、比例尺。
•  顺序与校验：尽量保持 a→… 行主序；必须重排时字母随图移动，panel 不拆不丢；合成后目检「孤行、空洞、错位、错切」，并把行高/行宽/空白率写入 layout 校验记录。
封面
•  PDF 或 DOCX 第 1 页以 ≥300 DPI 渲染；截页眉 + 标题 + 作者 + 日期，到作者行为止，不含摘要。
•  单位在首页底部时单独拼接，或加 11–12pt 灰色单位行；不要带摘要。
•  中文标题红色独立文本框；底部左侧「汇报人：」、右侧「汇报日期：」独立文本框，冒号后留白，不填占位符。标签默认22pt加粗，实际字号取22pt与本页红色标题字号中的较小值；不烧录。
•  截图最大区域由12.85×4.70扩大为12.93×5.20 in，左上角默认(0.20,0.20)；中文标题移至y≈5.55，身份标签移至y≈6.85。标题可用两行但不得与底部标签重叠。裁去无信息白边后等比放大；宽扁原图可分块拼接，不为填满区域拉伸或加入摘要。必要时微调位置并记录，确保底部标签在画布内。
•  图片 contain，绝不拉伸；放不下就缩图或分块，不要同时改宽高。

## 汇报提纲

采用白底四行横向分区，参考用户提供的「汇报安排」页面：左上角蓝色标题，无深蓝标题带；标题下为浅蓝细线。本页的页眉线使用 outline 配置覆盖公共粗蓝线。

每行左侧为蓝色正方形，内置居中的白色加粗编号01–04；右侧为蓝色加粗标题「研究背景」「技术路线」「结果讨论」「不足与展望」。编号独立于标题，不再附加一、二等中文序号。四行按配置的中心坐标等距排列，每行底部为长浅蓝细分隔线，扩大主体占用的纵向区域。

位置与字号读取 outline 配置：编号和标题的框顶坐标等于对应 row_center_y 减去自身框高的一半。文字水平与垂直居中，不用空格定位；四行标题共用相同文本框宽度。所有方块、编号、标题及线条均为原生可编辑元素，不把参考截图整页贴入。仅借鉴参考图版式，保持本技能四部分内容，不照搬图片中的五个章节。
