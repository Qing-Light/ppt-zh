# 论文组会 PPT

将用户提供的论文制成中文、可编辑的组会演示。先确定论文证据与主图，再写文案和排版。用户当前明确要求优先于本技能默认参数。

## 输入与依赖

- 必需：论文 PDF。缺失时询问用户，不编造论文内容。
- 可选：Fig.1–Fig.N 文件、仅供观察版式的参考 PPT、汇报人、汇报日期。
- 缺失汇报人时显示「汇报人：XXX」；日期缺失时显示「YYYY.MM」，不自行填当前日期。文件名日期可用 YYYY.MM 占位。
- N 只统计正文主图，排除补充图；核对图号与图注，无法确定 N 时询问。4–8 张为适用范围参考，不是删减主图的授权。
- 必须读取随本技能打包的 [references/humanizer-zh.md](references/humanizer-zh.md)，按其中流程逐块编辑并记录输出。该内置规范就是本流程所称的 `humanizer`，不依赖环境另行安装 `humanizer-zh`，也无须假设存在同名 API 或额外代理。若内置文件缺失、无法读取或输出为空，停止并说明，不模拟调用或伪造日志。
- 制作 PPTX 时读取当前环境提供的可编辑演示文稿制作技能，选择能生成原生文本框与表格的工具。使用其渲染检查能力；不得以整页图片代替可编辑演示稿。

## 内容与来源

1. 读取论文，记录标题、作者、单位、正文主图编号与 PDF 页码，列出 N+5 页清单及每页主张。英文论文翻译标题；中文论文保留原题。
2. 科学图片只使用该论文正文主图；封面另使用该论文首页标题、作者和单位区域。不得网络取图、AI 生图、重绘图表或根据文字/表格另造数据图。
3. 数字、单位、样本量、组名、图号与原文一致，不四舍五入、换算或补全；相关不改因果，「首次」「显著」仅在原文明确支持时使用。论文缩写首次给全称。
4. 允许裁切、等比缩放、在同一主图内重排完整 panel、添加中文标注。不跨图混拼，不把一张主图拆成多个结果页。保留字母、轴、图例、比例尺与显著性标记。
5. 从空白演示文稿新建。参考 PPT 仅用于观察版式，不另存为、不复制页面、母版、主题、图片、作者、数据或汇报人。

## 文案与内置 humanizer 流程

为以下每个块分别写准确草稿并标原文位置，再按内置 humanizer-zh 规范编辑，保存输出和上屏终稿：

- B1–B3：背景三段，顺序为大背景、已知、缺口，不提前写结果。
- R1–Rn 和 G：技术路线各行内容及目标句。默认 5 个研究阶段，按论文实际可用 4–6 个，不套用示例化学研究流程。
- F1–FN：每图先写 2–4 句草稿，单独 humanize，再仅通过删词和调序压为一句，不新增数字、判断、因果，保留必要条件与限定。无法忠实压缩时重写草稿并重新 humanize。
- L1–L3：证据边界、替代解释、不能证明。仅写论文提及或明确支持的内容；材料不足时说明缺口并询问，不为凑三点编造局限。

固定标签、表头、数字与原文图注不交给 humanizer。上屏正文必须来自对应编辑输出，不直接使用未编辑草稿。每图结论采用「对象 + 结果 + 边界」，不以「本图表明」开头；恰好一句、一个句号，最多两行。

## 固定页面结构

总页数 N+5，不额外增加目录、过渡、总结或致谢页。

| 页面 | 内容 |
| --- | --- |
| P1 | 论文首页截图或分块拼接，标题、作者、单位完整，无摘要；独立可编辑红色中文标题；独立汇报人和日期文本框 |
| P2 | 提纲：一 研究背景、二 技术路线、三 结果讨论、四 不足与展望 |
| P3 | 背景三个编号点，24pt，关键词红色 |
| P4 | 研究阶段 / 主要内容两列表格，默认 5 阶段，22pt 全部居中；下方 24pt 蓝色单行目标句 |
| P5–P(N+4) | 按 Fig.1–N 每页一张完整主图、一个小节标题、原文图注、底部一句结论 |
| P(N+5) | 不足三个编号点，24pt，限定词红色 |

排版前必读 [references/layout.md](references/layout.md)，其中包含画布、颜色、坐标、封面截取和 panel 排版的具体参数。

所有新增标题、正文、图注、表格、标注和结论使用原生可编辑元素；论文本身的主图与首页截图可为位图，不把「可编辑」误解为允许重绘论文图。

## 检查与交付

- 从 PDF 以至少 300 DPI 提取图片，图形等比缩放，宽高比误差 <0.5%。若外供主图与 PDF 不一致，以论文核实，不静默替换。
- 按 1920×1080 渲染并逐页目检，修复溢出、重叠、错切、失真和不可读文字。图注 9–10pt 加粗，结论 20pt 蓝色、关键词红色，图注与结论间距 0.05–0.06 in。
- 多 panel 重排后检查完整性、顺序、行宽、行高与空白率，将测量方法和结果记录于溯源文件的 layout 校验部分。参数无法同时满足时优先保护数据完整性，向用户说明具体冲突，不静默裁掉数据或声称通过。
- 核对 N+5 页、一图一句、封面无摘要且署名/日期可编辑；核对所有正文块都有 humanizer 记录。
- 若提供参考 PPT，对比两者 ppt/media 媒体哈希并追溯来源；相同媒体须核实是否确为直接从论文提取，确保没有复制参考文件素材，不能仅靠哈希宣称来源合格。
- 交付三个文件：`组会汇报_<第一作者>_<短标题>_<YYYY.MM>.pptx`、同名 `_预览.png`（全部页面缩略图总览）、同名 `_溯源.md`。
- 溯源文件逐块包含：块 ID、目标页、论文 PDF 页码与章节/图号/必要原文片段、草稿、humanizer 输出、上屏终稿。另记图片来源页与裁切区域、panel 重排映射、layout 校验和最终检查结果。没有记录视为未完成。
- 未实际渲染或未执行润色时明确说明未完成项，不把中间文件当成检查通过的最终稿。
